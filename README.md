# モンコレ配布ルーレット（画像込み・4ファイル版）

画像は monsters.json の中に入っているので、img フォルダはありません。
次の4つ（と README.md）を、GitHubのリポジトリのいちばん上の階層に置くだけで動きます。

- index.html
- monsters.json（約1.3MB）
- events.json
- .nojekyll

Settings → Pages で Branch を main、フォルダを / (root) にして Save すると、数分後に公開されます。
イベントの時間は events.json を書き換えて変えます（書き込める人を haruki だけにしておけば、他の人は変えられません）。

## イベントの延期・中止（events.json の書き方）
- `status`: `scheduled`（予定どおり）/ `postponed`（延期）/ `cancelled`（中止）
- `reason`: 画面に出すお知らせ（例: 運営の都合により延期します）
- `newStart`: 延期後の開始時刻。入れるとカウントダウンが新しい日程に切り替わり、「元の日程」が取り消し線で残ります。空なら「延期・日程未定」と表示されます。
- 中止にすると、「中止」の表示になり、カウントダウンは出ません。元の日程から14日たつと自動で表示から消えます。
- 繰り返しイベントの「この回だけ」の変更は `exceptions` に書きます。`date` は元の開催日（日本時間）です。
  `{ "date": "2026-12-01", "action": "cancel", "reason": "祝日のためお休み" }`
  `{ "date": "2026-12-08", "action": "postpone", "newStart": "2026-12-09T20:00:00+09:00", "reason": "1日ずらします" }`
- サイトの「イベント」→「管理者用」で入力すると、これらを含む events.json の内容が自動で作られます。


## お知らせ投稿（Discord風）とリアクション
events.json の各イベントに次の項目を足すと、イベントタブに投稿カードが出ます。
- `noticeTitle`: 投稿の見出し（例: "本日の管理者イベントについて"）
- `notice`: 本文。空行で段落、行頭 `# ` で見出し、`- ` で箇条書き、`**太字**` が使えます。JSONでは改行を `\n` と書きます（管理者フォームの出力を貼れば自動です）。
- `author`: 投稿者名（省略時は「管理者」）
- `reactions`: 基準のリアクション数。例 `{"👍":191,"❤️":52}`
リアクションを押した分は、見ている人の端末だけに保存されます（静的サイトなので全員共通の集計はできません）。
